Регрессия от ужесточения валидации сочетаний, найдена пользователем и исправлена. `ParseHotkey` теперь требует Ctrl, Alt или Win (Shift допустим только дополнительным), и сохранённые `Shift+A` / `Shift+Q` были отклонены — глобальные сочетания не регистрировались вообще. Виджет в этот момент был скрыт в трей, и вернуть его клавишами стало нечем. Исправлено по существу: при отклонении сохранённой комбинации host откатывается на `Ctrl+Alt+Space` / `Ctrl+Alt+N`, регистрирует их, записывает в `window.json` и сохраняет `hotkeyError`, чтобы замена была объяснена, а не молчаливой. Проверено: оба сочетания заняты процессом Delo (ошибка 1409), окно видимо, `displayAffinity=17`. Правило: отклонять сохранённую настройку можно только вместе с рабочим откатом.

Windows Sandbox на этой машине не запускается: `WindowsSandboxRemoteSession.exe` не может загрузить `hostfxr.dll` с `0x80070005`. Причина установлена — у каталога пакета в `WindowsApps` отсутствуют ACE для `ALL APPLICATION PACKAGES` и `ALL RESTRICTED APPLICATION PACKAGES`, которые есть у рабочих пакетов, а у всех 40 проверенных каталогов стоит нестоковый `Michael: FullControl`. Перерегистрация пакета и перезагрузка не помогли. По решению пользователя идёт переустановка компонента через цикл необязательной функции. **Шаг 1 выполнен:** `Disable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -NoRestart`, состояние `Disabled`, требуется перезагрузка. **Шаг 2 после перезагрузки:** `Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -NoRestart`, снова перезагрузка, затем сверить ACL каталога пакета с рабочим и прогнать `app/tests/run-windows-sandbox.ps1 -Version 0.1.5`. Флага `-Remove` не было, полезная нагрузка сохранена, откат возможен.

Цель: законченный виджет по SPEC, автономная поставка Inno Setup и публичный исходный код/релиз. Ни один успешный графический стенд не закрывает продукт целиком.

## Решения реализации

Новая команда пользователя — довести сам виджет до конца — переводит работу в реализацию. П1–П8 SPEC используются как явно записанные рабочие defaults, а не как цитата одобрения каждого пункта пользователем. Они сохраняют требования и могут корректироваться. Лимит текста — 4000 символов; сохраняемый checkpoint таймера — каждые 5 секунд. Лицензия приложения планируется MIT, проверяется состав ресурсов перед публикацией.

Стек: Win32 C++17, Windows Composition Backdrop без захвата дисплея, прозрачный WebView2 с локальными HTML/CSS/ES modules. WebView2 SDK 1.0.4191.47, установленный Evergreen runtime. Нативный процесс один; два окна используют одно хранилище с ревизиями. Локальный JSON envelope сохраняется атомарно с резервной копией, в профиле пользователя. JS domain отделён от UI и файловой системы. Преломление кромки U01 после отказа от WGC временно остаётся незакрытым.

## Правила harness

Каждый этап оставляет реальные журналы и повторяемую команду. PASS означает проверенный сценарий; отсутствие среды или внешнего монитора означает UNVERIFIED, не PASS. Последний completion audit сопоставляет каждый ID SPEC и V01–V12 с кодом и свидетельствами. Не маркировать цель завершённой, пока остаётся обязательный непроверенный результат. Реальные личные данные и скриншоты рабочего стола не попадают в публикуемые evidence.

Исходные графические проверки: architecture/STABILITY.md и FRAME-PACING.md. Они относятся к стендам и не подменяют H05.
