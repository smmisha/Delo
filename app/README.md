# Delo — приложение в разработке

12 сентября обычная копия в `app/bin` обновлена и перезапущена с сохранением данных. Последний этап добавил локальный Whisper в обе капсулы; ранее перенесены оконные исправления и отмена событий репутации. Установщик с новым голосовым вводом пока не собран.

Delo — локальный планировщик для Windows 11 x64: постоянный виджет рабочего стола, быстрое добавление задач, таймер, архив, корзина и репутация. Интерфейс поддерживает русский, украинский и английский языки, системную, светлую и тёмную темы. Нативный Win32-host объединяет живой Windows Composition Backdrop и прозрачный WebView2 для резкого интерфейса.

Публичный выпуск поддерживается через GitHub Releases. Основные сценарии работают, но полный аудит `SPEC.md`, несколько мониторов/DPI и чистая Windows без установленного WebView2 пока не закрыты. Win+D и реальный сон на основном ноутбуке уже проверены в production host.

Актуальная граница доказательств: [повторный UI-аудит](../architecture/UI-AUDIT-20260911.md) и [обзор прокрутки групп](../architecture/UI-REVIEW-20260912.md). Исправления перенесены в обычную копию `app/bin` и входят в текущий installer 0.1.9; наряд и проверки последних правок — в [аудите 12–17 сентября](../architecture/UI-AUDIT-20260912.md). Старые sleep/Win+D результаты не считаются повторным тестом новой сборки.

## Сборка

Нужны Windows 11, Visual Studio Build Tools с C++ workload, Windows SDK с C++/WinRT и PowerShell. Node.js нужен только для JS-тестов. `toolchain.ps1` автоматически находит последнюю подходящую установку MSVC и Windows SDK; при необходимости используйте `DELO_VC_ROOT`, `DELO_SDK_ROOT` и `DELO_SDK_VERSION`.

```powershell
./setup.ps1
./setup-voice.ps1
./build.ps1
node --test tests/*.test.mjs
./test-store.ps1
./test-renderer.ps1
```

`setup.ps1` загружает WebView2 SDK 1.0.4191.47 и проверяет SHA-256. `build.ps1` статически связывает MSVC runtime и WebView2Loader, поэтому конечному пользователю не нужны Visual Studio Build Tools или Windows SDK. Для работы приложения нужен Microsoft Edge WebView2 Runtime.

`setup-voice.ps1` готовит локальный Whisper и multilingual Small Q5_1 (около 190 МБ), проверяет хеши и подписи библиотек Microsoft CRT/OpenMP для поставки рядом с движком. `build.ps1` проверяет manifest и копирует комплект в `voice/`. При использовании микрофона сеть не нужна. Архитектура и границы проверок — [VOICE.md](../architecture/VOICE.md).

## Установщик

Для локальной упаковки нужен Inno Setup 6.7 или новее и подписанный Microsoft автономный установщик WebView2 x64.

```powershell
./setup-distribution.ps1
./package.ps1 -Version 0.1.9
```

Если Inno Setup установлен в другом месте, передайте путь через `-Compiler`. Результат и его SHA-256 создаются в `dist/`. Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\Programs\Delo`; права администратора для самого Delo не требуются. Обычный пакет включает подписанный WebView2 bootstrapper, который запускается только при отсутствии подходящего runtime; `-Offline` включает полный установщик WebView2.

Перед обновлением или удалением закройте Delo через значок в области уведомлений. Обновление заменяет файлы приложения. Удаление убирает приложение, ярлык и принадлежащую Delo запись автозапуска, но сохраняет пользовательские задачи и не удаляет общий WebView2 Runtime.

## Использование

- Нажмите микрофон, продиктуйте фразу и нажмите ещё раз для распознавания. Язык совпадает с языком интерфейса. Результат добавляется к черновику; сохраните задачу после проверки текста. Крестик или Escape отменяет голосовую операцию без потери черновика.

- Введите задачу в нижнем поле и нажмите Enter. Shift+Enter добавляет новую строку. В быстром окне Escape отменяет ввод и очищает черновик; в основном окне Escape скрывает список.
- Левый клик по значку Delo в трее сразу открывает быстрый ввод; быстрый двойной клик остаётся тем же действием без переключения окон. Полный планировщик открывается через Ctrl+Alt+Space или пункт «Открыть список» в меню трея. Клик вне быстрого ввода скрывает его.
- Глобальное сочетание списка по умолчанию — Ctrl+Alt+Space, быстрого окна — Ctrl+Alt+N. Конфликты показываются в интерфейсе, а прежние рабочие сочетания сохраняются.
- Автозапуск выключен по умолчанию и меняется в настройках.
- Win+Shift+S и Print Screen автоматически готовят виджет к снимку. Для работающего Lightshot учитываются его настроенная клавиша (проверен Insert) и нажатие на его значок в трее. Настройки Lightshot не изменяются. Материал удерживает последний кадр на время съёмки; через 15 секунд живое стекло восстанавливается автоматически. Пункт трея Delo «Снимок экрана (15 с)» остаётся доступен для ручной подготовки.
- Виджет скрыт от захвата экрана намеренно: его стекло строится по снимку рабочего стола за ним, поэтому окно не должно попадать в этот снимок. Значит, и при демонстрации экрана зрители его не видят. Пункт «Режим демонстрации» в меню значка в трее отпускает оба окна в захват и заменяет стекло матовой подложкой; при повторном выборе стекло возвращается. Режим не сохраняется: после перезапуска Delo он выключен, а зрители при включённом режиме видят ваши задачи.

Обычные данные находятся в `%LOCALAPPDATA%\Delo\tasks.json`, резервная копия — `tasks.json.bak`. Хранилище пишет атомарно, проверяет схему и блокирует сохранение поверх повреждённого файла. Явное восстановление из backup сохраняет копию повреждённого оригинала. Таймер использует общий монотонный отсчёт нативного процесса; checkpoint записывается каждые 5 секунд и после аварии восстанавливается в состоянии паузы.

Нативный renderer использует Windows Graphics Capture, D3D11 и HLSL для размытия и преломления внешнего фона. WebView сохраняет матовый tint, направленные блики и грани. При перетаскивании и изменении размеров кадры обновляются внутри системного цикла перемещения; фон не замораживается до отпускания мыши. Самозахват предотвращается исключением обоих окон из записи экрана. Режим снимка временно останавливает обе сессии захвата, сохраняя GPU-материал, и снимает исключение; перед возобновлением оно возвращается обоим окнам. Реальный sleep/resume ранее проверялся на другой сборке; после этих изменений не повторялся.

## Изолированный harness

`bin/Delo.exe --harness=<имя>` использует `bin/test-output/sessions/<имя>` и включает локальный диагностический CDP-порт 9223. Обычный запуск не включает harness. Всегда задавайте отдельное имя сессии: безымянный старый каталог может содержать реальные личные задачи. Каталоги `bin`, `vendor`, `test-output`, `dist` и снимки рабочего стола не публикуются.

Повторяемые сценарии `tests/run-ui-audit.ps1` и `tests/audit-backup.ps1` создают новые именованные профили, используют настоящие HWND/клавиши/указатель, сохраняют JSON и снимки и ожидают штатного выхода. Для сборки без замены запущенного EXE используется `build.ps1 -OutputDirectory <каталог>`. Актуальные проверки и незакрытые требования перечислены в [отчёте аудита](../architecture/UI-AUDIT-20260911.md). Старый installer 0.1.2 и его предыдущие install/relaunch проверки остаются историческим результатом; новый runtime требует отдельного цикла поставки.
