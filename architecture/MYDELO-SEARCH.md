## Поиск
- Ядро: `core/search.mjs` — `matchingIds` (снимок совпавших id при смене запроса) и `filterGroups` (порядок сохраняется, пустые группы скрыты). Задача, переставшая совпадать после правки, остаётся до смены запроса.
- UI: капсула `#main-search-box` (`role="search"`) на месте надписи, `aria-controls="task-scroll"`, число результатов в `#status`. Ctrl+F (перехват в capture-фазе) и пункт «Найти» в меню «⋯». Escape очищает, затем закрывает. Закрытие — при скрытии виджета, кнопке «скрыть», добавлении задачи. Сохранённая свёрнутость групп не меняется. Пустой результат предлагает открыть архив/корзину с тем же запросом.
- Native: `AreBrowserAcceleratorKeysEnabled=FALSE` через `ICoreWebView2Settings3`, чтобы Ctrl+F доходил до страницы. Копирование/вставка/отмена проверены не отдельно.
