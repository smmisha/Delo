## Причина и исправление

Собственный `evaluate(expression)` передавал только строку в `Runtime.evaluate`. Функция из вызова `evaluate(callback, argument)` исчезала при JSON-сериализации запроса. Настоящий CDP воспроизводил ошибку `-32602` с отсутствующим обязательным `params.expression`.

Для callback применяется `Runtime.callFunctionOn`; значения передаются через массив CDP arguments. Старые выражения-строки продолжают работать. Динамические аргументы аудитов переведены на этот путь вместо ручного экранирования строк.

В CI добавлен `audit-harness.test.mjs`: дочерний Node inspector обрабатывает настоящий WebSocket/CDP, подменяется только обнаружение страницы. Проверяются строки, аргументы-файлы, два селектора, JSON со спецсимволами, текст с JS-подобным содержимым, async-результаты и исключения.

В live-раннере также исправлены обнаружение страниц через явный разбор JSON и запись window.json без BOM. При диагностике `@(Invoke-RestMethod ...)` возвращал один объект `System.Object[]`, содержащий обе страницы. Исправленный путь различает about:blank, main и quick. Запись профиля проверена настоящим Windows PowerShell 5.1.26100.9711: BOM отсутствует, тестовые сочетания сохранены.
