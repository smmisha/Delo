# Проверка правок Claude Code — 12 сентября 2026

Уточнение пользователя: сохранить матовость и оптические грани, устранить замораживание фона при перетаскивании. Финальная правка сохраняет слои материала и tint шейдера 0.72 / 0.76. Промежуточное удаление CSS-подложек отменено.

## Исправления

- `WM_ENTERSIZEMOVE` больше не вызывает `Freeze(true)`. Таймер окна обновляет GPU в модальном цикле Windows; после жеста снимается. Вне жеста работает прежний событийный цикл и детектор изменений.
- Заголовки групп остаются sticky, занимают одну строку управления высотой 44 CSS px, имеют скругление и плотную локальную подложку. Лишние 17 px вертикальных отступов и тяжёлая тень убраны. Фокус клавиатуры не обрезается прокруткой.
- Resize-grip быстрого окна больше не передаёт pointerdown обработчику перемещения капсулы. До исправления измерено: x 100 → 160, ширина 517 → 517, dragRequests 4 → 5 при попытке растянуть правый край.
- Режим снимка закрывает только WGC-сессии, сохраняя GPU и последний материал. Прежний `Suspend(true)` уничтожало GPU целиком. Пауза применяется к обеим view до снятия WDA; исключение возвращается обеим до возобновления любой сессии. Пункт трея доступен на RU/UK/EN, watchdog — 15 секунд. Во время съёмки quick не скрывается при потере фокуса.
- Составной снимок harness сохранён; для скрытого окна теперь выдаётся понятная ошибка вместо зависания CDP. `capture-widget.ps1 -Screen` проверяет обычный захват Windows.
- Исправлены устаревшие UI-тесты маршрутов настроек/меню/сроков и переводов. Смена темы проверяется по сохранённым данным и фактическому состоянию UI, а не только значению select.

## Windows Sandbox и ограничения

Сбой Sandbox предшествовал Delo: журнал Application содержит отказ загрузки `hostfxr.dll` с 0x80070005. Точная ACL-причина не доказана. Claude записал отключение компонента и незавершённый цикл восстановления. На момент проверки WindowsSandbox.exe и регистрация пакета не найдены; `Get-WindowsOptionalFeature`, даже вне sandbox Codex, требует административного Windows-токена, поэтому текущий Enabled/Disabled/Pending не подтверждён.

Исправлены runner и guest: уникальный каталог, реальный marker запуска гостя, свежий атомарный результат, отдельные таймауты и проверка passed. Проверены синтаксис трёх PS1 и шесть mock-сценариев runner. Системные компоненты, ACL и перезагрузка в этой проверке не менялись; реальный Sandbox остаётся UNVERIFIED. Подробности — `DISTRIBUTION.md`.

`app/bin/Delo.exe` пересобран. Installer после этих правок не пересобирался. Реальные сон/пробуждение новой сборки, смена DPI/мониторов и длительная нагрузка не проверены. Это локальная проверка и исправление приложения, не подтверждение готовности публичного релиза.

## Уточнение дизайна: капсула и верхний край списка

По последующему уточнению пользователя заголовок группы остаётся закреплённым, строки плавно исчезают под ним, отдельная плашка не нужна. Эти изменения заменяют прежнее оформление sticky-полосы; настройки используются как визуальный образец.

- У быстрой капсулы внешняя оболочка высотой 84 CSS px имела радиус 32 px, поле высотой 66.4 px — 24 px. Обе поверхности теперь используют капсульное скругление, автоматически ограниченное половиной высоты. Размеры, отступы, кнопки и native geometry не менялись.
- Фон, blur и тень sticky-заголовка убраны. Заголовок сохраняет исходную кнопку сворачивания и видимый клавиатурный фокус. Наведение выделяет шеврон, не возвращая отдельную плашку.
- Только строки каждой группы собраны в маскируемый контейнер. Переход 14 px повторяет маску края настроек; его положение следует за нижней границей закреплённого заголовка, включая момент вытеснения следующей группой. Маска не затрагивает текст заголовка. Обновление объединено через requestAnimationFrame, изменения размеров отслеживает ResizeObserver. Scroll padding сохраняет читаемость фокуса.
- Проверки в отдельном профиле: 11 group/material, 8 scroll/focus/capsule, 12 resize и 32 JS — PASS. Просмотрены реальные снимки светлой/тёмной тем, ширины 420/320 CSS px, обеих капсул и смены групп. Снимки и JSON: `app/test-output/scroll-shape-20260912/`.
