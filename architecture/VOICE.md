# V02 — локальный голосовой ввод

12 сентября 2026. Реализация и проверки выполнены на выбранной пользователем Astra 6 High. Terra подходит для ограниченных UI-правок; этот этап затрагивает native audio, дочерний процесс, lifecycle, две формы и поставку зависимостей.

## Поведение

Микрофон в основном окне и быстрой капсуле начинает запись с системного устройства ввода. Повторное нажатие завершает запись и запускает распознавание. Крестик или Escape отменяет запись/распознавание, сохраняя черновик. Скрытие окна, блокировка сессии, сон и выход отменяют активную операцию. Распознанная фраза добавляется к текущему черновику и остаётся доступной для редактирования; задача автоматически не создаётся.

Язык распознавания совпадает с языком интерфейса: русский, украинский или английский. Ошибки отсутствующего движка, микрофона, слишком короткой/тихой записи и таймаута локализованы. При превышении 4000 символов текст сохраняется для сокращения пользователем. Голосовые состояния занимают существующую капсулу, не меняя её высоту, материал, даты и время.

## Архитектура и зависимости

`Voice.h` записывает mono PCM 16 kHz / 16 bit через Windows waveIn в отдельном потоке. Запись ограничена 60 секундами. Whisper запускается скрытым отдельным процессом с пониженным приоритетом, 8 CPU-потоками и таймаутом 120 секунд. GPU не требуется. Job object завершает дочерний процесс при отмене или закрытии host. Идентификатор сессии не позволяет запоздавшему результату восстановить отменённый текст. Поток записи не обращается к WebView, COM и задачам.

Используются [whisper.cpp b5130](https://github.com/ggml-org/whisper.cpp/releases/tag/b5130) и multilingual Small Q5_1, 190 085 487 байт. Загрузка выполняется только разработчиком через `app/setup-voice.ps1`. Работа установленного микрофона не использует сеть, API-ключи и разрешения браузера. Временные WAV/текст находятся в отдельном каталоге процесса под `voice-temp` и удаляются после обычного завершения, ошибки или отмены. При аварийном завершении Windows остаточные файлы возможны; автоочистка после аварии пока не реализована.

Обе MIT-лицензии входят в комплект. Release-библиотеки Microsoft CRT/OpenMP копируются из каталога Redist установленного toolchain с проверкой подписи Microsoft и включаются в manifest. Это [локальная поставка redistributable DLL](https://learn.microsoft.com/en-us/cpp/windows/determining-which-dlls-to-redistribute); обновлять их в поставке — ответственность проекта. Сборка проверяет SHA-256 каждого файла manifest. Бинарные зависимости и модель не добавляются в Git.

## Проверки

- 40 JS unit PASS, включая 6 голосовых: исходный текст, поздний ответ, ранний stop, ошибки, переполнение, RU/UK/EN.
- 10 native PASS: настоящий Whisper, путь с кириллицей и пробелами, отсутствие runtime/input, асинхронность, отмена дочернего процесса и удаление временных файлов.
- `audit-voice.mjs`: 11 live PASS через настоящий host/Whisper. RU и EN — синтезированные контрольные фразы, UK — запись Google FLEURS validation row 0, ID 1578. В этой проверке короткие фразы обработаны за 3,19 / 3,30 / 3,19 секунды (RU/UK/EN); это замер примеров, не гарантия скорости любой записи. Украинское имя распознано неточно, редактирование доступно.
- Настоящий Windows-микрофон открыт, короткая запись возвращает ожидаемую ошибку, Escape сохраняет текст. Проверены отмена распознавания и скрытие быстрой капсулы.
- Светлая тема, русский текст ошибки, reduced motion и минимум 296 CSS px в быстрой капсуле: сообщение и крестик помещаются в высоту 84 CSS px. Тёмные состояния обеих форм визуально проверены.
- Регрессии: 3 tray PASS; синхронные размеры HWND/WebView/material при настоящем изменении окна с шагом 16 и 8 мс PASS. Renderer после voice healthy, errors=0.
- Storage/hotkey 20/20 и GPU renderer 9/9 PASS после финальной подготовки зависимостей. Компиляция host и native-тестов прошла без предупреждений.

Локальные журналы и снимки: `app/test-output/voice-audit-02/`; native: `app/test-output/voice-native/`. Для повторения голосового harness нужны контрольные `en.wav`, `ru.wav`, `uk.wav` в `test-output/voice-fixtures` рядом с harness EXE. Подстановка файла вместо микрофона доступна только при `--harness=<имя>`.

**Границы:** запрет микрофона в настройках Windows проверен только как обработка ошибки в unit-тесте; системные privacy-настройки пользователя не переключались. Точность на живой диктовке пользователя, длинных/шумных записях, физические multi-monitor/DPI, чистая Windows и installer с новым движком требуют отдельной проверки. V02 не объявляет весь продукт полностью проверенным.
