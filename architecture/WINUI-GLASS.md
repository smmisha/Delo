# WinUI 3 / HLSL — результат исследования

10 сентября 2026. **Преломление не подтверждено; кандидат не принят.** Создан [отдельный WinUI-пробник](../prototypes/winui-glass/README.md). Производственный стек Delo не выбран.

## Конфигурация

Windows 11 25H2 x64, масштаб 125%; .NET SDK 8.0.425; LiquidGlassWinUI **1.0.3** из NuGet; Windows App SDK **2.2.0**, self-contained. Использована готовая нативная DLL пакета. [Версии модулей](evidence/winui-glass-2026-09-10/modules.json), [хеши исходников и сборки](evidence/winui-glass-2026-09-10/build.json).

Сборка завершилась без ошибок и предупреждений. SDK распакован в папку прототипа, системный SDK не устанавливался. Первый запуск .NET сообщил о создании ASP.NET development certificate; последующие сборки устанавливают `DOTNET_GENERATE_ASPNET_CERTIFICATE=false`. Существующие сертификаты пользователя не удалялись.

Библиотека патчит внутренние функции App SDK в собственном процессе. Это риск сопровождения даже при успешной отрисовке. [Происхождение и лицензия](../prototypes/winui-glass/THIRD_PARTY.md). Исследованный HEAD отличается от NuGet по managed-коду и шейдерам; результат относится к пакету 1.0.3.

## Проверки

Каждый итоговый сценарий выполнялся в отдельном процессе. Перед эффектом прошли проверки видимости окон, DPI, красного/зелёного XAML-контроля и движения сетки без линзы. Захват разрешён только когда центральная точка принадлежит HWND пробника. Внутренний источник — XAML, внешний — отдельное собственное Win32-окно; внутренняя сетка в этом случае скрыта.

Сравниваются индексы преломления 1 и 2.2, толщина 28, увеличение 1. Blur, dispersion, tint и блики отключены для проверки геометрии. Изменённым считается пиксель с суммой различий RGB больше 70; кромка должна менять больше 300 пикселей, центр — меньше 100. Движение источника проверяется отдельно.

| Сценарий | Источник до эффекта движется | Смещение у кромки | Движение после эффекта | Итог |
|---|---|---|---|---|
| Внутренний светлый, стандартный host | Да | 0 | 0 | Не прошёл |
| Внутренний тёмный, стандартный host | Да | 0 | 0 | Не прошёл |
| Внешний светлый, прозрачный host | Да | 0 | 15 567 пикселей | Не прошёл |
| Внешний тёмный, прозрачный host | Да | 0 | 15 567 пикселей | Не прошёл |

`LastError` пуст и нативная DLL загружена во всех сценариях. Это не доказывает исполнение шейдера. На внутренней сцене видимое обновление прекращается после подключения эффекта, хотя XAML Rendering продолжает вызываться и координаты элементов меняются. Причина внутри конвейера не установлена. Внешняя сетка может быть видна через прозрачную поверхность; её движение не доказывает семплирование текстуры шейдером.

## Ограничения и следующий эксперимент

Ранние снимки с неверным DPI и прогоны под перекрывающими окнами исключены из итоговых свидетельств. Предварительный обход цветокоррекции через reflection также не дал преломления; это не полноценная проверка исправленного пакета.

Кисть 320×240 DIP немного обрезана клиентской областью 394×294 физических пикселя. Финальный layout не оценивался; даже доступная левая кромка не показывает эффекта. Производительность, desktop-parenting, Win+D, ввод и восстановление Explorer **с этим материалом не проверялись**. Результаты прежнего простого HWND не переносятся на WinUI автоматически.

Следующий эксперимент — управляемый источник текстуры и минимальный GPU-шейдер через документированный Direct3D/Win2D-путь. Сначала доказать смещение собственной живой сцены, затем отдельно проверить получение внешнего фона и исключить самозахват виджета. Это план, ещё не реализованный код. Повторять полный конвейер LiquidGlassWinUI без новой проверяемой гипотезы не следует.

Принятый макет и SPEC не изменены. У Delo нет Git-репозитория, `git diff` недоступен. Публикация и установщик не выполнялись.

Обновление: следующий отдельный GPU-эксперимент выполнен успешно для явной текстуры и внешнего HWND — [GPU-GLASS.md](GPU-GLASS.md). Это не исправление LiquidGlassWinUI; прежний отрицательный результат сохраняется.
