myDelo — наброски названия и поиска

Цикл 3 ноября 2026. Это макет в HTML/CSS, а не снимок настоящего UI: стекло изображено условно, преломление не показано. Для реальных снимков после выбора понадобится harness (этап M1/M2). Решение G1 принято (все видимые имена — myDelo), поиск — вариант A (3 ноября).

1. Надпись в шапке

Знак на 14 % выше кегельной высоты и на 8 % ниже базовой линии (BRAND.md); выносной «y» стоит рядом со знаком и до «D». Доступное имя — текст h1, без aria-label. Ширина 320 DIP с тремя кнопками шапки.

2. Поиск, вариант A: капсула на месте надписи

Ctrl+F или «Найти» в меню «⋯». Задачи не сдвигаются; пока поиск закрыт, шапка как в 0.3.10 (кроме надписи). Края шапки — зона перетаскивания, само поле окно не тащит.

3. Решения для G2

  1. Надпись: 1 («my» тоньше) — рекомендация: сохраняет вес «Delo» и читается как один знак; 2 теряет контраст у вторичного цвета в светлой теме (проверить ≥ 4.5:1), 3 — самое безопасное по ширине.
  2. Кнопки шапки при поиске: оставить все три (A1–A4) — рекомендация; «×» вместо «скрыть» (A5) сужает риск ошибочного скрытия, но меняет привычный набор.
  3. Подсветка совпадений: без неё (A2′) — рекомендация: проще, нет риска для таймерных перерисовок; с ней (A2) нагляднее для длинных названий.

Самопроверка по apple-liquid-glass и ui-ux-pro-max проведена по макету, не по настоящему UI; контраст «my» вторичным цветом и ширину 320 DIP с реальным шрифтом нужно подтвердить на harness.
