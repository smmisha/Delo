# WinUI / HLSL feasibility probe

Отдельный исследовательский проект Delo. Проверка на 10 сентября 2026 **не прошла**: преломление не видно ни на внутреннем, ни на внешнем источнике. Это не приложение и не выбранный производственный стек.

## Воспроизведение

Windows 11 x64, свободная область экрана слева. Скрипт показывает только собственные окна, сохраняет предыдущий фокус и закрывает их после проверки. Не переключайте окна во время измерений: проверка принадлежности HWND остановит недостоверный захват.

```powershell
./setup-sdk.ps1
./build.ps1
./run.ps1
```

SDK 8.0.425 скачивается с Microsoft в `.tools`, ZIP проверяется по SHA512. NuGet использует отдельный `.packages`; версии и транзитивные зависимости сохранены в `packages.lock.json`. Системный SDK не устанавливается. Проверка NuGet Audit в этом исследовательском build отключена; это не аудит безопасности зависимостей.

Каждый сценарий запускается в отдельном процессе. Результаты и BMP сохраняются в `bin/Release/net8.0-windows10.0.19041.0/win-x64/artifacts/<UTC timestamp>`. Код завершения 1 означает непройденную проверку, а не успешный запуск приложения.

Аргументы EXE:

- `--standard-host`: обычный непрозрачный WinUI host; без флага используется прозрачный SystemBackdrop.
- `--external`: отдельное собственное Win32-окно с живой сеткой; без флага сетка находится внутри XAML.
- `--dark`: тёмная контрольная палитра.
- `--direct-glass`: только диагностический обход промежуточной цветокоррекции через reflection внутренних полей пакета. Не использовать в продукте. Предварительная проверка этого режима также не показала преломления; он не входит в итоговую матрицу.

До эффекта проверяются красный/зелёный XAML-контроль, согласованность DPI и движение открытой сетки. После подключения сравниваются коэффициенты преломления 1 и 2.2: движение у кромки, неизменность центра и обновление источника. `LastError == null` и загрузка DLL сами по себе не означают работающий эффект. Видимость внешней сетки через прозрачное окно также не доказывает её семплирование шейдером.

Размер кисти 320×240 DIP; фактический клиент меньше из-за оставшейся системной рамки (394×294 физических пикселя при 125%). В отчёте это ограничение сохранено; финальная геометрия виджета здесь не проверяется.

## Зависимости и границы

LiquidGlassWinUI 1.0.3, Windows App SDK 2.2.0, self-contained x64. Используется готовая нативная DLL из NuGet, не сборка native-кода из исходников. Библиотека зависит от внутренних ABI App SDK и патчит функции **в своём процессе**. Обновление App SDK требует повторной проверки, незаметно менять версии нельзя.

`vendor` — локальная копия для изучения, сборке не нужна и в публикацию не включается. Исходный дизайн Delo не изменён. [Происхождение и лицензия](THIRD_PARTY.md), [полный результат](../../architecture/WINUI-GLASS.md).
